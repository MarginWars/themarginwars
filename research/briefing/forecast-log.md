# Margin Wars Briefing: Forecast Log

The Briefing keeps a running log of dated forward calls. Each call is scored against what actually happened, so the method improves over time.

**Format (one row per call):**
- **ID:** F-YYYYMMDD-n, where the date is the run when the call was made.
- **Made:** the date the call was made (America/Los_Angeles).
- **Call:** a specific event that can be checked against a public source.
- **Likelihood %:** our probability that the call resolves "yes".
- **Resolve by:** the date after which the call is scored.
- **Leading indicators:** public signals that would move the probability before the resolve date.
- **Status:** open / hit / miss / too early (resolve date not reached, or the event was overtaken).
- **Score date:** the run on which it was scored. When scored, add the Brier score (outcome 1 or 0 minus the probability, squared).
- **Notes:** sources and any adjustment made.

**Scoring:** every weekly run first checks open calls against primary sources. It updates the status and records any lesson in method-changes.md. Likelihoods are not edited after the fact; a revised view goes in as a new call that references the old ID.
