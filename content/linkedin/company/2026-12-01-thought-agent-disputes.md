When the buyer is an agent, someone still has to carry the dispute.

Agentic checkout demos end at "order placed." The P&L starts at the chargeback.

The Monday move: price the agent channel before it prices you.
1. Give agent orders their own channel. One cost-per-order line: agent fee, interchange, scheme fees, refunds and disputes.
2. Run it against a direct holdout, so you see the real difference, not the demo.
3. Before you start: set merchant of record flow by flow, flag agent transactions at checkout, and bind every agent purchase to a user mandate.
4. Add one dispute reason to your own tracking: "agent bought the wrong thing."

That last one matters most. You can't price a loss you can't see.

The question we can't settle, so we're asking the people who know: today, when an agent buys the wrong thing, which dispute reason does that chargeback actually land under, and who ends up eating it: the merchant, the agent platform, or the cardholder?
